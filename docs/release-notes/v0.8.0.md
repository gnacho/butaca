# v0.8.0 - a Jellyfin client, a rebuilt interface, and the first package you can install

Butaca is now a client for a Jellyfin server and nothing else, with its interface rebuilt around what you were watching. This is also the first release of this repository that carries an installable package: the v0.6.5 release announced the client but shipped no file to install.

## Breaking: this version signs in to Jellyfin only, not to Plex

The 0.6 line carried both. The Plex sign-in, the profile picker and the code that talked to plex.tv are not in this package, so if you watched through a Plex account, this version cannot reach it and no setting brings it back. You need a Jellyfin server and an account on it.

## If you ran a 0.6.x build: it stored your Jellyfin password, and this version stores a token

The 0.6 line, including v0.6.5, wrote the password you typed at sign-in to `/media/developer/com.butaca-jellyfin.json` in clear text. The file was created readable only by its owner, so another app on the television could not open it, but anyone with a shell on the set, or a copy of that file, could read the password.

**What to do:** nothing has to be done to use this version. If that file could have been read or copied by someone else, change the password on your Jellyfin server, which is the only way to take a copy of it out of use.

**What is fixed, and what is not:** 0.8.0 uses the password once, obtains an access token from your server, and rewrites the file without the password. It cannot reach a copy that was already taken. The token it keeps instead is revocable from your server at any time, and disconnecting the server in Settings removes it from the television.

## If you are updating from a 0.6.x build: install over it

Install this package over the app you have rather than uninstalling it first. The file the 0.6 line wrote holds the server address and the user, so this version reads them, signs in once as described above, and keeps a token. You should not have to type the address or the user again.

The Plex sign-in and profile list that 0.6.x kept are left where they are, and this version does not read them. There is no longer a reporting question to answer, because the reporting subsystem is not in this build.

## What's new

- **Signing in with Quick Connect.** The television shows a code, you approve it from a device already signed in to your server, and no password is typed with the remote.
- **A rebuilt interface.** Home, the detail page and the player chrome were redrawn: a detail column that keeps the film's own artwork beside it, a wide Continue Watching row, visible Back controls, a Settings gear at the top right, and a quieter ground under the page.
- **A Favorites tab.** The items you hearted are listed on their own, in one place, instead of only being reachable through the library grid.
- **Libraries read as what they are.** Other Videos are separate from Movies, the A to Z rail is available on Jellyfin, and the recently added shelf is off until you turn it on in Settings.
- **The end of an episode is your choice.** Settings decides whether the next episode starts by itself, waits for you, or does nothing.
- **The tracks you chose stay chosen.** A series remembers the audio and subtitle track you were watching it with and starts the next episode on them.
- **Subtitles you can size and place.** Subtitle text has its own size and position instead of one fixed look.
- **Deep links from a launcher.** A launcher that hands Butaca an item identifier opens that item, including when the app is already running.
- **An idle screen that leaves the panel dark.** The screen saver no longer paints a bright image over an OLED panel.
- **Audio sync and trickplay.** The player can shift audio against the picture, and it shows the server's trickplay thumbnails while you scrub where the server has them.

## Fixed

- **DTS audio no longer starts playing and then fails.** A file whose DTS track the television cannot decode is sent to the server to transcode instead of being direct-played into silence.
- **A stream that stops short no longer looks like the end of the film.** A transfer that ends before the length it announced is treated as a failure and retried from the same byte, rather than reported to the player as the end of the media.
- **The hero backdrop stays under the shelves.** Moving through Home no longer drops the artwork behind the page.
- **Settings reconnects its preferences and its sign-out.** Changing a preference no longer leaves the page showing a value the app did not take, and signing out actually leaves the account.
- **The keyboard stays open in Search.** It no longer closes while you are still typing, outside the capture scenarios that used to hide it.
- **Dolby Vision follows what the server reports.** The picture mode is chosen from the range the server sends for the file, instead of being assumed.
- **BACK closes a field edit before it leaves the screen.** One press ends the edit, the next one goes back.
- **A plain address on your own network is accepted at sign-in.** The form takes an address literal it can prove is local, and still refuses to send a password over a name it cannot check.

## Changed

- **A Developer Mode shell can read a short storage diagnostics file** beside the app's logs, so a storage problem can be reported without root. It carries no token, no account name and no server address, and the television clears it when it restarts.
- **There is no reporting of any kind.** No crash reports, no usage counters, no analytics and no consent question: the subsystem was removed from this tree rather than switched off.
- **Butaca's own code is licensed GPL-3.0-or-later.** The complete corresponding source of this release is attached to it.
- **The interface language is chosen in Settings**, and the app follows the television until you choose otherwise.

## Compatibility

- **Plays video, verified by watching it - 2019 LG sets, on the build before this one.** The television this project is developed on is an LG 49SM9000PLA, which reports platform release 4.10.2 (LG markets this generation as webOS 4.5). It ran the Jellyfin build and played video there in October, before the interface rebuilt in this release; nobody has watched video on v0.8.0.
- **Plays video, reported by someone else - nobody, on this version.** The playback reports this project holds come from a 2019 set and a 2021 set on earlier releases, and both were the Plex client. No third party has reported running this build.
- **Starts, and nothing further is known - every other firmware from webOS 4.0 up.** The loader resolves this binary's libraries and symbols against the firmware images webosbrew publishes; the matrix is in the [technical audit](https://github.com/gnacho/butaca/blob/main/docs/release-audits/v0.8.0.md). That grades startup and says nothing about whether video plays.
- **Does not start - webOS 3.9.2 and older.** Symbols the app needs are missing there, so the process is killed before anything appears.

If your set is in the middle two groups, [tell us what happened](https://github.com/gnacho/butaca/issues). It working is as useful a report as it failing.

## Known issues

- **Some 2019 sets on LG's k5lp or k3lp chip, installed through Developer Mode, will not play video.** LG's Developer Mode sandbox can withhold a device the video path needs, and the app says so instead of crashing. On a rooted set with Homebrew Channel the failure screen offers Repair; without root there is no fix: #74.
- **2018 sets on firmware reporting platform release 3.9.3 sign in and browse, but video has not been seen to start**, and no error is reported.
- **A crash on televisions built on LG's k6hp chip**, seen only in reports from owners and not reproduced here, because no such set is available: #174.
- **Playback on webOS 5 and newer has not been reported on this version.** The app starts there; this release changed the interface and the player chrome, and nobody has watched a video on those sets since.

## Help test this release

**If you install this on any television, tell us whether video plays.** This is the first stable package of the Jellyfin client, and no one has watched a film on this exact build. **If your set is from 2021 or newer, or runs webOS 5 or later**, your report is the one this project does not have. **If you are updating from a 0.6.x build**, say whether you were signed in without typing the address and user again. [Open an issue](https://github.com/gnacho/butaca/issues). It working is as useful a report as it failing.

## Installing

Download **com.butaca_0.8.0_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). You do **not** need a rooted TV.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.butaca_0.8.0_arm.ipk
```

[Installing and checking a download](https://github.com/gnacho/butaca/blob/main/docs/install-and-verify.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. Butaca is licensed GPL-3.0-or-later and bundles FFmpeg under LGPL-2.1-or-later; the complete corresponding source for both is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.8.0](https://github.com/gnacho/butaca/blob/main/docs/release-audits/v0.8.0.md).
