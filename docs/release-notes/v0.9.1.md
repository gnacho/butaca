# v0.9.1 - Settings follows the television, and the Interface group is gone

The Settings page keeps the settings. The **Interfaz** group it used to end with - language, licences and About - is removed: the interface takes its language from the television, and the licence and project documents live in the repository and in every release rather than on a screen nobody opens from a sofa.

## What changed

- **The language is the television's.** Butaca draws Spanish or Belarusian when the set's own UI language is one of them, and English for any other. Nothing is stored, so there is no override to find, and signing out, deleting local data or reinstalling cannot change the language. A language you change on the television applies the next time Butaca starts, because the set's locale is read at startup.
- **The Interface group is gone from Settings.** Settings is now Servidor, Reproducción and Audio y subtítulos. The picker that chose a language, the guide to translating the app and the two documents that opened from that group are removed with it, including their pages and their rows.
- **The licence and About texts are not in the app any more.** The privacy notice, the open-source licences, the FFmpeg and source position, the trademark note, the contact address and the About text remain in the repository and are published with each release. Nothing about the licence under which this package is distributed changed.

Nothing about how Butaca plays a file changed in this release.

## Fixed

- **The interface no longer offers a language the television already chose.** The old setting defaulted to the set's language but could be overridden, and the override outlived sign-outs and reinstallations; the interface now has one source and no drift.

## Known issues

- If the television's UI language is neither Spanish nor Belarusian, Butaca draws English. There is no way to ask for Spanish on a set whose own language is not Spanish.
- The Settings page still carries the rows this app has: *Desconectar* in Servidor, and the audio-sync, up-next, recently-added and screen-saver rows in Reproducción.

## Downloading it

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.butaca_0.9.1_arm.ipk
```

[Installing and checking a download](https://github.com/gnacho/butaca/blob/main/docs/install-and-verify.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps.
