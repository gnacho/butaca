# v0.9.0 - the interface the redesign called for

The menus are now the ones in the design: a neutral dark top bar that is the same whether or not a sheet is open, a server switcher drawn as the design's card, and Settings on one page in two columns instead of a single column of rows down the middle. Nothing about how the app plays a file changed in this release.

## What's new

- **A rebuilt top bar.** The bar is one dark slab with the profile disc, Inicio, Películas, Series, Favoritos and Buscar - the last three drawn as icons - the Settings gear and the clock. The wordmark and the capsule around the row are gone, because the design does not have them, and the row now starts at the bar's own left edge rather than centred.
- **The focused tab wears the accent.** The tab the remote is on is filled in the design's violet with a soft penumbra and its label turned white; the tab you are watching stays a quiet plate. Idle labels are the design's muted white.
- **No Back control in the bar.** The disc that used to replace the profile avatar while a sheet was open is gone: a sheet closes with the remote's BACK, which every one of them already answered, and the bar no longer changes shape when one opens.
- **The server switcher is the design's card.** A 560px warm-neutral card with the servers listed as rows - a green dot for the one the screens are showing, its address and the server's own Jellyfin version, an `ACTIVO` tag, and the row that adds another. The server's version is the one learned the last time this app signed in to it.
- **A server row tells you which Jellyfin it is.** The address now carries the server's own version (`192.168.1.10 · Jellyfin 10.9`), read from the server itself rather than typed in.
- **Settings is one page.** Servidor, Reproducción, Audio y subtítulos and Interfaz as one two-column grid of cards, with the group names in the design's gold caps, at the design's own type sizes. The pickers still open onto the row they belong to.
- **One focus colour across the menus.** A focused menu row, card or list entry is a white plate at 16%, as the design draws it, instead of this app's violet; the violet is kept for the marks that are the design's own.

## Fixed

- **The current tab's label is white.** It was being drawn white at 55% opacity - the idle grey it was supposed to leave - because the ink was mixed with a helper that keeps the source colour's alpha. Visible on every screen that wears the bar.
- **A font role could crash the bar.** The coverage table was sized for five font roles and the sixth (the avatar's ExtraBold cut) indexed past its end, which panics at paint time on a television. It is sized from the role count now.
- **Fraunces is cut at the optical size the design uses.** The shipped cuts were the 72pt instance and drew about 7% narrow; the display titles were measured against the design and came up short.

## Known issues

- The three track preferences the design draws as cards in *Audio y subtítulos* - preferred audio language, subtitle mode and subtitle language - are not in this build. That group shows this app's subtitle size, position and background instead.
- Settings still carries the rows this app has and the design does not: *Desconectar* in Servidor, and the audio-sync, up-next, recently-added and screen-saver rows in Reproducción.

## Downloading it

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.butaca_0.9.0_arm.ipk
```
