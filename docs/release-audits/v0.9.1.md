# Release audit - v0.9.1

The evidence behind the v0.9.1 release note. Written for a webosbrew reviewer, a contributor auditing an old release, and us in a year. The section at the bottom is generated from the artifact that was published; everything above it was written by a person before the release ran.

## Device test evidence

| | |
|---|---|
| television | LG OLED, webOS 4.5. The package is installed from the published `.ipk` with `com.webos.appInstallService`, and the boot line in the event log is the evidence that the packaged app, not a developer build, is what ran |
| server | the repository's own synthetic Jellyfin server (`tests/mock_jf.py`) for the simulator run; a real Jellyfin server for the device boot |
| suite | `make check` on the merged tree - 3950 lib, 3991 hostsim, 102 storage, 5 Python harness cases, all passing |
| suite | `make check-replay` - 3 fixtures, 6 replays, every one `verdict=SAME`; the three anchors were re-recorded onto the new screen-shape pin |
| suite | `cargo +nightly check --lib --no-default-features` - clean, and CI's cross-build for `armv7` built the target and ran its artifact assertions |
| perf | not measured; the change removes rows from one page and none of the animated chrome changed |
| by hand | the Settings page in the desktop simulator at 1920x1080 against the mock server in Spanish: three groups, no Interface rows |

**What this release proved, and what it did not.** Every claim about the page's row set is host evidence: the simulator drew the page with Servidor, Reproducción and Audio y subtítulos and nothing else. The language resolution is covered by the host suite, which drives each shipped catalog and the locale parser the set's reply goes through. What the simulator cannot answer is what any release cannot answer from this machine: text rasterization on LG's FreeType and frame pacing on the set's GPU. Neither is touched by this patch, and the device step for this release is the install and boot of the published package, recorded in the release conversation.

## What this release deliberately did not do

- **No in-app licence, privacy or About text.** Those documents live in the repository and in each release. The GPL and LGPL position, the FFmpeg source offer and the trademark note are unchanged and still published with the package's materials.
- **No language override.** A set whose UI language is neither Spanish nor Belarusian gets English, and there is no way to ask for another catalog on that set.
- **Nothing was removed from the settings themselves.** The playback, subtitle, server and idle-screen controls are the same ones, in the same groups, with the same values.

## External compatibility reports known at release time

- None addressed by this release.

## Compatibility tiers, and what moved

- No line moves. This release changes one page's row set and where the UI language comes from; it claims the same firmware support as v0.9.0.

## Known issues at release, with provenance

- An English-only set cannot be asked to draw Spanish. The set's locale is the only source, chosen deliberately so the two cannot disagree.
- The Settings page retains this app's own rows (*Desconectar*, audio sync, up next, recently added, screen saver) that the design does not draw.
