# Release audit — v0.9.0

The evidence behind the v0.9.0 release note. Written for a webosbrew reviewer, a contributor auditing an old release, and us in a year. The section at the bottom is generated from the artifact that was published; everything above it was written by a person before the release ran.

## Device test evidence

| | |
|---|---|
| television | LG OLED, webOS 4.5 (`com.butaca.debug` developer install on the same set) |
| server | the repository's own synthetic Jellyfin server (`tests/mock_jf.py`) for the desktop and simulator runs |
| suite | `make check` on the release tree — 3981 lib, 4022 hostsim, 102 storage, 352 harness cases, all passing |
| suite | `make check-replay` — 6 fixtures, verdict `SAME` on all six |
| perf | not run for this release |
| by hand | the interface at 1920x1080 in the desktop simulator (`ui-sim`): the bar, the server switcher and Settings measured against the design's own DOM, element by element |

**What this release did not prove.** The device tier was not run before publishing: this checkout is on a Linux x86_64 host, the webOS cross-toolchain publishes no build for it, so the ARM binary comes from CI rather than from this machine. The `.ipk` that CI publishes is the artifact a television should be tested with, and the device line above belongs to that install — it is recorded here as pending, not as passed. Nothing about playback changed in this release; the changes are the shared chrome, the server switcher and the Settings page, and the tier that can see them is the simulator, which is where they were measured.

## What this release deliberately did not do

- **The three track preferences the design draws** — preferred audio language, subtitle mode, subtitle language — are not implemented. The `Audio y subtítulos` group keeps this app's subtitle size, position and background.
- **Rows the design does not have are kept.** *Desconectar* stays in Servidor because it is this app's only sign-out outside the server switcher; the audio-sync, up-next, recently-added and screen-saver rows stay in Reproducción because nothing else reaches them.
- **The Settings page is the design's page, not its content**: the two-column grid, the group caps, the card geometry and the type rungs are the design's, measured from its DOM; the cards themselves are this app's settings.

## Reports this release rests on

- No third-party report is addressed by this release. The interface work is the owner's own redesign mockup, held against it element by element.

## External compatibility reports known at release time

- None addressed by this release.

## Compatibility tiers, and what moved

- No line moves. This release was not run on a television before publishing (see above), so it claims nothing the previous release did not already claim.

## Known issues at release, with provenance

- The design's three track preferences are absent from Settings; recorded in the note and in the plan for this work.
- Rows the design does not draw remain in Servidor and Reproducción, because nothing else reaches them.
