Font License 1.1 (see OFL.txt):

  (Phaedra Charles, Flavia Zimbardi).
- `instrumentsans-var-latin.woff2`: Instrument Sans (variable, roman),
  (c) The Instrument Sans Project Authors (Rodrigo Fuenzalida, Newglyph).

Fetched from Google Fonts. Self-hosted so the page makes no third-party
requests.
